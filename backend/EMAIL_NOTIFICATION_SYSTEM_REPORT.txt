### 🔍 HOW IT WORKS:

1. **Task Scheduling (Celery Beat)**
   - Periodic tasks run on schedule:
     * send_daily_reminders: Every 5 minutes
     * send_domain_alerts: Daily at 9:30 AM UTC

2. **Notification Creation**
   - Tasks query database for reminders/domains matching criteria
   - Create Notification records for matches

3. **Email Sending (Signal Handler)**
   - Signal fires when Notification is created
   - Immediately calls send_notification_email()
   - Email sent via Gmail SMTP
   - Notification marked as email_sent=True

4. **Email Delivery**
   - Recipients: All users with SUPER_ADMIN role or is_superuser=True
   - Subject: Alert: {notification_title}
   - From: noreply@grehasoft.com
   - Template: Notification message + type + module

### 🚀 PRODUCTION SETUP:

For production with Redis:

1. Update config/settings.py:

   CELERY_BROKER_URL = "redis://redis-server:6379/0"  
   CELERY_RESULT_BACKEND = "redis://redis-server:6379/0"
   CELERY_ALWAYS_EAGER = False  # Remove or set to False
   CELERY_WORKER_POOL = 'prefork'  # Use prefork on Linux

2. Start services:

   celery -A config worker -l info
   celery -A config beat -l info
   redis-server

3. Email sending becomes async:
   - Signal queues email task to Celery
   - Worker processes emails asynchronously
   - Better performance for high volume

### 🔄 REMINDER LOGIC:

**Reminders Task** (check_and_create_reminder_notifications):
- Runs every 5 minutes
- Checks for reminders where due_date <= today AND is_completed=False
- Creates REMINDER_DUE notifications for today
- Creates REMINDER_OVERDUE notifications for past dates
- Avoids duplicates by checking existing notifications

**Domain Task** (check_and_create_domain_notifications):
- Runs daily at 9:30 AM UTC
- Checks for domains where expiry_date is within 30 days
- Creates DOMAIN_EXPIRING notifications
- Checks for expired domains (expiry_date <= today)
- Creates DOMAIN_EXPIRED notifications
- Avoids duplicates

### 📧 NOTIFICATION TYPES:

Type: REMINDER_DUE
- When reminder due_date == today

Type: REMINDER_OVERDUE
- When reminder due_date < today AND is_completed=False

Type: DOMAIN_EXPIRING
- When domain expiry_date is within 30 days
- When domain expiry_date > today AND expiry_date <= today + 30 days

Type: DOMAIN_EXPIRED
- When domain expiry_date <= today

All types trigger immediate email sending to admin users.
